# عربی نحو کا مکمل رہنما — آسان اردو

**مقصد:** طالبِ علم ترکیب (Tarkeeb) اور اعراب پر مہتمکن بنے — کوئی جملہ دیں تو اس کی پوری بنا سمجھ لے: کس قسم کا ہے، عامل کون ہے، ارکان کیا ہیں، زوائد کیا ہیں، ہر لفظ کا اعراب کیا ہے، اور پورا جملہ کس محل پر بیٹھا ہے۔

یہ رہنما اس ڈیٹا سیٹ کا خلاصہ ہے — تفصیل عربی میں `nahw/` کی فائلوں میں موجود ہے۔

---

## ۱۔ جملے کے چھ سوال — دھیان میں رکھنے والا خاکہ

کوئی بھی جملہ آئے تو ان **چھ سوالوں** کے جواب دو — جملے کی پوری بنا کھل جائے گی:

1. **یہ جملہ کس قسم کی ہے؟** — پہلا لفظ دیکھو: اسم سے شروع؟ (اسمیہ) — فعل سے؟ (فعلیہ) — انشائی آلہ سے؟ (انشائیہ: امر، نہی، استفہام، تمنی، نداء، تعجب، قسم، مدح و ذم)
2. **عامل کون ہے؟** — کس نے کام کیا: فعل؟ حرف؟ اضافہ؟ ظرفیت؟
3. **ارکان کیا ہیں؟** — اسمیہ: مبتدأ + خبر — فعلیہ: فعل + فاعل (+ مفعول) — ناقصہ: ناسخ + اسم + خبر — قسم: آلہ + اسم قسم + جواب
4. **زوائد کیا ہیں؟** — توابع (نعت، عطف، بدل، توکید)، ظرف، حال، جار و مجرور، عدد و تمییز
5. **ہر لفظ کا اعراب اور علامت کیا ہے؟** — رفع/نصب/جر/جزم — حركت سے، حرف سے، یا حذف سے
6. **پورے جملے کا محل کیا ہے؟** — جملہ خبر بن سکتی ہے (محل رفع)، حال (محل نصب)، جوابِ قسم (محل جذر)، یا بلا محل۔

> **سنہری اصول:** پہلے عامل دیکھو، پھر جو اس سے متاثر ہوا، پھر اس کی علامت، پھر پورے جملے کا محل۔

## ۲۔ بنیادی تصورات — آسان اردو میں

| اصطلاح | آسان مطلب |
|---|---|
| **مبتدأ** | وہ اسم جس سے اسمیہ جملہ شروع ہو (الطالبُ مجتهدٌ → الطالبُ مبتدأ) |
| **خبر** | وہ لفظ جس سے فائدہ پورا ہو (مجتهدٌ خبر) |
| **فعل** | کام کرنے والا لفظ — ماضی، مضارع، امر |
| **فاعل** | کام کرنے والا — ہمیشہ مرفوع (نجحَ الطالبُ) |
| **مفعول به** | جس پر کام ہوا — ہمیشہ منصوب (قرأَ الكتابَ) |
| **نعت (صفت)** | پچھلے اسم کی بٹی — اسی کے ساتھ چلتا ہے (الكتابُ الجديدُ) |
| **مضاف و مضاف الیہ** | اضافے کا جوڑ: کتابُ اللهِ — پہلا اسم دوسرے کو جذر کرتا ہے |
| **ظرف** | وقت یا جگہ بتانے والا اسم — ہمیشہ منصوب (اليومَ، تحتَ) |
| **حال** | فاعل کی حالت فعل کے وقت — منصوب (جاءَ مسرورًا) |
| **تمییز** | ابہام دور کرنے والا — عشرون کیا؟ کتاباً |
| **استثناء** | ایک کو نکال دینا — ما حضرَ إلا زيدٌ |
| **منادى** | پکارا گیا اسم — يا محمدُ |
| **نواسخ** | وہ الفاظ جو مبتدأ و خبر کا اعراب بدل دیتے ہیں: کان، انّ، ظنّ |
| **مبنی** | جس کا اعراب نہیں بدلتا — ضمیر، اسمِ اشارہ، حروف… |
| **منصرف** | عام اسم: رفع میں ضمہ، نصب میں فتحہ، جذر میں کسرہ |
| **غیر منصرف** | جسے تنوین نہیں لگتی — رفع میں ضمہ، نصب اور جذر میں فتحہ (أحمدَ، مکۃَ) |

## ۴۔ تمثیلات — مشکل مقامات کی روزمرہ مثالیں

### خبرِ محذوف (نعم الطالبُ)
سوچو ریس ختم ہوئی اور تم ایک طالب کی طرف اشارہ کر کے کہتے ہو: «نِعْمَ الطالبُ!» — گویا کہہ رہے ہو: **یہ طالب (مبتدأ) سب سے بہتر ہے (خبر)**۔ لیکن «بہتر» (مفضَّلٌ) تمہارے **دل میں ہے، زبان پر نہیں** — یہی **خبرِ محذوف** ہے۔

### تمییز مقدر (نعم الماءُ زجاجٌ)
ایک صاف پانی کا گلاس تھام کر کہو: «یہ پانی — اس کی صراحت زجاج جیسی ہے!» — «زجاج» پانی کا **تمییز** ہے: یہ بتاتا ہے کہ پانی کا فضل کس چیز میں ہے۔

### حال (جاءَ مسرورًا)
جملہ ویڈیو ہے تو **حال** اس کا **عین لقطہ** ہے: «جاءَ» یہ بتا رہا ہے کہ آیا — اور «مسرورًا» اس وقت کے چہرے کی خوشی دکھا رہا ہے۔

### تمییز عام (عشرون کتاباً)
عدد ایک ڈھیر کی طرف اشارہ کرتا ہے — ڈھیر کا کیا مطلب؟ تمییز کھول دیتا ہے: **کتابوں** کا ڈھیر۔

### استثناء (ما حضرَ إلا زيدٌ)
ایک ٹوکری: «تمام سبزے خراب ہو گئے» — پھر تم ایک گاجر باہر نکال دیتے ہو: «سواے اس کے» — وہی **استثناء** ہے: منفی جملے سے ایک کو نکالنا۔

### ظنّ اور افعالِ قلب (ظننتُ العلمَ نافعًا)
تمہارے سر میں ایک **مترجم** ہے: آنکھ نے کوئی منظر دیکھا، دماغ نے اس کا کلام بنا دیا: پہلی ترجمانی «العلمَ» (من دیکھا)، دوسری «نافعًا» (کیا فیصلہ)۔ لیکن اگر صرف آنکھ سے دیکھا (رأی بصریہ) تو ایک ہی ترجمانی: «رأيتُ الهلالَ»۔

### افعالِ شروع (أخذَ الطالبُ يقرأُ)
کیمرے نے صرف **شروع ہونے کا لمحہ** ریکارڈ کیا: «أخذ» وہ لمحہ ہے، «الطالبُ» (جس سے شروع ہوا) اور «يقرأُ» (جو کیا گیا) — دونوں منصوب۔

### جار و مجرور (في المسجدِ)
**جار بٹوہ ہے اور مجرور اس کے پیسے** — لیکن بٹوہ تنہا کچھ نہیں کرتا، اسے **کمرے سے لٹکانا پڑتا ہے** (تعلق): «ذهبتُ إلى المسجدِ» (فعل سے)، «الطالبُ في المسجدِ» (خبرِ محذوف سے: حاضرٌ)۔

### عسى (عَسَى المطرُ نازلٌ)
بادل سے گھری آسمان کی طرف دیکھ کر کہنا: «شاید بارش ہو» — «عسى» نے **المطرُ کو اوپر اٹھا دیا (اسم، مرفوع)** اور **نازلٌ کو نیچے رکھ دیا (خبر، منصوب)** — کان کی طرح کام کرتا ہے۔

## ۷۔ مشق کا طریقہ (روزانہ ۱۵ منٹ)

1. آلہ چلاؤ: `python3 nahw/tarkeeb.py quiz` — ایک جملہ آئے گا
2. اس پر **چھ سوال** کے جواب دو (کاغذ پر لکھو)
3. حل دیکھو: `python3 nahw/tarkeeb.py corpus <ID>`
4. اپنا جملہ آزماؤ: `python3 nahw/tarkeeb.py parse "جملہ"` 
5. نئے الفاظ `lexicon.json` میں، نئے جملے `sentences.json` میں ڈالو — پھر `validate` اور `test` چلاؤ

**آیات و احادیث لانے کے لیے:** `python3 nahw/fetch_examples.py wbw 2:153` (قرآن کلمہ بہ کلمہ) — اور `hadith bukhari 1`

# sources.md — المصادر المفتوحة (قرآن وحديث) | Open-access Quran & Hadith APIs

كل المصادر أدناه **مُختبَرة حيًّا** من هذا المشروع. أداة الجلب: `python3 nahw/fetch_examples.py` (بمكتبة بايثون القياسية فقط).

## القرآن الكريم

| المصدر | المفتاح | الأنسب لـ | مثال مباشر (مُختبَر) |
|---|---|---|---|
| **Al Quran Cloud** — `api.alquran.cloud/v1` | لا يحتاج مفتاحًا | نص الآية بكل الروايات، ترجمات، تفسير (الميّسر)، بحث | `GET /v1/ayah/2:153/quran-uthmani` |
| **QuranCDN (qdc)** — `api.qurancdn.com/api/qdc` | لا يحتاج مفتاحًا | **كلمة بكلمة**: كل كلمة برسم عثماني + ترجمة — أساس التركيب | `GET /verses/by_key/2:153?words=true&word_fields=text_uthmani&translations=131` |
| **Quran.com API v4** — `api.quran.com/api/v4` | لا يحتاج مفتاحًا للمحتوى (تسجيل للتطبيقات) | آيات، فصول، كلمة بكلمة، ترجمات، تفسير، صوت | `GET /verses/by_key/2:153?words=true` |
| **fawazahmed0/quran-api** — CDN جيتHub | لا يحتاج مفتاحًا ولا خادمًا (jsDelivr) | تنزيل كامل الرسم برواية معينة | `GET .../editions/ara-quranuthmanihaf/2/153.json` |
| **Quranic Arabic Corpus** — `corpus.quran.com` | تحميل البيانات مفتوح | **إعراب آلي لكل كلمة**: نوعها، حالتها (رفع/نصب/جر)، جذرها، وزنها — مرجع للمقارنة مع تركيبنا | واجهة ويب + تنزيل بيانات |
| **مكتبات نصية للتوثيق** — `shamela.ws` و`al-maktaba.org` | كتب التراث كاملة نصًّا (مفتوحة للقراءة) | التحقق من الشواهد والتراجع — منها تُتوصَّل لكتب النحو التي تتضمن أحاديث الشواهد | ويب (لا API رسمي) |
| **مكتبة الجامعة** — `aljameah.com` | متجر كتب (ليست نصية) | للحصول على طبعات ورقية | ويب |
| **تجويد القرآن** — `tangheemalquran.com` | موقع تطبيقي (لا واجهة برمجية عامة) | بحث في القرآن ومراجعات الحفظ — مرجع بشري للشواهد، لا يُستدعى آليًّا | واجهة ويب فقط |
| **قرآن بيديا (QuranPedia)** | لا واجهة برمجية عامة | مذاهب القراء وتطبيقات القرآن — مرجع بشري | ويب/تطبيق |

## الحديث النبوي

| المصدر | المفتاح | الأنسب لـ | مثال مباشر (مُختبَر) |
|---|---|---|---|
| **fawazahmed0/hadith-api** — CDN | لا يحتاج مفتاحًا | كل الكتب (بخاري، مسلم، أبو داود، الترمذي…) عربيًّا + ترجمات، بدون خادم | `GET .../editions/ara-bukhari/1.json` (حديث رقم ١) |
| **Sunnah.com API** — `api.sunnah.com/v1` | مفتاح مجاني بالتسجيل | أحادية اللغة الإنجليزية + عربي، بروابط دقيقة | `GET /v1/hadiths/1` مع `X-API-KEY` |
| **HadithAPI.com** — `/public/api/hadiths` | مفتاح مجاني بالتسجيل | بحث وتصفية بالكتب والأبواب والدرجات | `GET /public/api/hadiths?apiKey=...` |

## أوامر الأداة الجاهزة

```bash
python3 nahw/fetch_examples.py ayah 2:153          # نص الآية برسم عثماني
python3 nahw/fetch_examples.py wbw 2:153           # كلمة بكلمة + ترجمة (للتركيب)
python3 nahw/fetch_examples.py hadith bukhari 1    # حديث من الصحيح
python3 nahw/fetch_examples.py candidate 2:153     # سجل جاهز للإضافة إلى sentences.json
```

## كيف تُضيف آية أو حديثًا إلى بيانات التركيب

1. `candidate 2:153` → يطبع سجلًا جاهزًا فيه `source: {type: quran, ref: "2:153"}` والنص المُبسَّط.
2. أضف كلماته الجديدة إلى `lexicon.json`، ثم كمل `words[]` بالإعراب و`structure` و`awamil`.
3. أضف السجل إلى `sentences.json` ثم:
   `python3 nahw/tarkeeb.py validate && python3 nahw/tarkeeb.py test`

مثال منفَّذ: **S033** «إنَّ اللهَ مع الصابرينَ» (البقرة ١٥٣) — مضاف للبيانات الآن بمصدره.

## ملاحظات

- تقديرات الرفع للـCDN (jsDelivr) مناسبة للقراءة والتنزيل، لا للإنتاج الثقيل.
- حقوق النصوص: القرآن الكريم مرادفات حرة؛ الحديث عبر fawazahmed0 مبني على مجموعة DuSunnah المفتوحة — راجع ملف الترخيص في كل مستودع عند النشر.
- Quranic Arabic Corpus يستخدم إطارًا لغويًّا حديثًا (تحليل صرفي + أدوار) وليس إعرابًا كلاسيكيًّا حرفيًّا — استعمله مرجعًا للمقارنة، لا بديلًا.
